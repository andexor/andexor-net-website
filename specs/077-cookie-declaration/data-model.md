# Data Model: Cookie Declaration

No data of the site's own is stored. The declaration's text and cookie list come from Cookiebot, which gets them by
scanning andexor.net. The site reads and writes none of it.

- **Cookie Declaration element**: one script element with `id="CookieDeclaration"`, in the footer.
- **Declaration content**: added by Cookiebot beside the element after the script runs; not part of the site's markup.
