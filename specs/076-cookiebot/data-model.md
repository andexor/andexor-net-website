# Data Model: Cookiebot

No data of the site's own is stored. Cookiebot, the third-party service, holds each visitor's consent choice in its own
cookie and its own records. The site reads and writes none of it.

- **Consent banner**: shown by Cookiebot when a visitor has no saved choice.
- **Domain ID**: `ba75dc6a-d85e-4740-891e-dd0cc31a62dd`, in the `data-cbid` attribute.
