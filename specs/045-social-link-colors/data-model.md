# Data Model: Social Link Colors

No stored data. The links' icon color by state:

| State | Selector | Color token |
|---|---|---|
| Rest | `.an-footer__social-link` | `--blue-300` |
| Hover | `.an-footer__social-link:hover` | `--blue-200` |
| Pressed | `.an-footer__social-link:active` (written after `:hover`) | `--blue-400` |
| Keyboard focus | `.an-footer__social-link:focus-visible` | none set, so the resting color |
