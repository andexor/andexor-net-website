# Web Hosting

We keep your site running so you can focus on your business.

## AWS

We have more than 5 years of experience with:

- running a secure site
  in a virtual private server (VPS)
  using Elastic Compute Cloud (EC2),
  inside a Virtual Private Cloud (VPC)
- running mini apps in a Lambda function
- identity management with users,
  security groups, and keys in IAM
- storing data in MySQL and PostgreSQL
  via Relational Database Service (RDS) and Aurora
- key/value lookups with DynamoDB
- file storage with Elastic Block Service (EBS)
- object storage with Simple Storage Service (S3)
- load balancing with
  Elastic Load Balancer (ELB)
- domain registration and DNS management
  with Route 53
- sending and receiving messages with
  Simple Queue Service (SQS)
- sending notifications with
  Simple Notification Service (SNS)

## Google Cloud
