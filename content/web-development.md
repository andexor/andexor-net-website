# Web Development

## Need a new website?

Let's start with your imagination.
We can create something beautiful, usable, and accessible.

ready to handle loads of new customers.

Let's give it a fresh, new look and modernize it.
We can draw upon award-winning examples
for design inspiration to get started
and add as many features as you like.

We got you.
We can create pages listing each one of
your products, services, and locations.

properly listed on Google Maps.

## Want a blog?

No problem.
We'll set you up with a content management system
to publish your articles.

## How about some cool forms, right on your website?

No sweat. We'll make it professionally branded on your site.

## Want to setup an e-commerce shop?

Let us help you setup a shop
to sell products and services.

## Got a site that loads too slow?

Let us help you speed it up.
We can monitor page load times,
identify the bottlenecks,
and optimize each stage

## Need a web application?

With over 20 years of experience,
we can build an application
with the features you need.
We can even add certain types
of features that are common to
large, enterprise applications,
but not normally found on
small business websites,
at much lower costs.

This includes things like:

- automating routine tasks
- processing tasks in the background
- queuing up tasks to process in a batch
- database development and management
- automatic data archival and removal
- dashboards for monitoring system health
- measuring business growth analytics
- third-party system integrations
- automatic failover for business continuity

## How about an AI agent?

Let's enter some common facts, questions,
and answers into a knowledge base.
Then we can setup a chat assistant to answer questions
for your customers and get a conversation started.
We can also create an AI assistant to answer
phone calls and book appointments for you.
